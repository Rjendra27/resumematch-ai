# ResumeMatch AI

ResumeMatch AI is an AI-powered resume and job description analyzer designed to help candidates understand how well their resume matches a specific job.

## Features

- 🎯 Resume Match Score
- ⭐ ATS Compatibility Analysis
- 🚀 Top 5 Resume Actions
- 🔑 Keyword Placement Analysis
- 📊 Skill Gap Dashboard
- ✏️ Resume Bullet Point Improver
- 📝 Current → Suggested Resume Changes
- 💼 Project Relevance Analysis
- 📋 Job Requirement Analysis
- 🤖 AI Resume Assistant
